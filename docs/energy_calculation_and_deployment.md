# 에너지 발전량 계산 로직 및 Docker 배포 가이드

## 1. 에너지 발전량 계산 로직

이 애플리케이션은 사용자가 제주도 지도에서 선택한 위치를 기반으로 예상 태양광 발전량과 수익을 계산합니다.

### 1.1 지역별 기본 계수 (Regional Base Coefficients)
태양광 발전 효율은 지역에 따라 다릅니다. 제주도를 한라산(중심점)을 기준으로 4개의 구역(4분면)으로 나누어 계산합니다.

| 지역 (Region) | 설명 | 기본 계수 (Base Coefficient) |
|--------|-------------|------------------|
| **JEJU_EAST** | 동부 (성산) | `10.5923` |
| **JEJU_WEST** | 서부 (고산) | `9.5636` |
| **JEJU_SOUTH** | 남부 (서귀포) | `11.1436` |
| **JEJU_NORTH** | 북부 (제주시) | `11.4818` |

### 1.2 위치별 랜덤 변동성 (Positional Randomness)
국지적인 환경 차이(구름, 그늘, 패널 방향 등)를 반영하기 위해, 사용자가 특정 위치를 선택(클릭/터치)할 때마다 기본 계수에 소폭의 랜덤 값을 더합니다.

- **로직**: `최종 계수 = 기본 계수 + 랜덤 변동값`
- **변동 범위**: `+/- 0.2` (-0.2 ~ +0.2 사이의 랜덤 값)
- **효과**: 같은 동부 지역이라도 클릭하는 픽셀 위치가 다르면 결과가 미세하게 달라져 사실적인 느낌을 줍니다.

### 1.3 계산 공식
최종 예상 수치는 다음과 같이 계산됩니다:

1.  **일일 발전량 (kWh)** = `설치 면적 (m²) * 최종 계수`
2.  **월간 발전량 (kWh)** = `일일 발전량 * 30`
3.  **잉여 에너지 (kWh)** = `월간 발전량 * 0.7` (약 70%를 잉여 전력으로 가정)
4.  **예상 수익 (KRW)** = `잉여 에너지 * 250원`

## 2. Docker 배포 가이드

코드 변경 사항을 실행 중인 Docker 환경에 적용하는 방법입니다.

### 2.1 개발 모드 (Hot Reload)
현재 `docker-compose.yml` 파일은 **볼륨 마운트(Volume Mounting)** 방식으로 설정되어 있습니다.
```yaml
    volumes:
      - ./energy-trading-app:/app
```
이는 로컬의 `energy-trading-app` 폴더가 컨테이너 내부의 `/app` 폴더와 직접 연결되어 있음을 의미합니다.

**사용 방법:**
- **이미지 재생성 불필요**: React 컴포넌트나 계산 로직 수정과 같은 단순 코드 변경 시에는 Docker 이미지를 다시 빌드할 필요가 *없습니다*.
- **자동 업데이트**: 파일을 저장하면 컨테이너 내부의 Next.js가 변경 사항을 감지하고 자동으로 재컴파일(Hot Module Replacement)합니다.

### 2.2 변경 사항 확인 방법
컨테이너가 이미 실행 중이라면:
1.  코드를 수정하고 저장합니다.
2.  브라우저를 새로고침(F5) 하면 변경된 로직이 적용됩니다.

컨테이너가 실행 중이 아니거나 `package.json`을 수정했다면:
1.  PowerShell에서 다음 명령어로 컨테이너를 실행합니다:
    ```powershell
    docker-compose up frontend
    ```
2.  패키지 설치 등 완전한 재빌드가 필요한 경우:
    ```powershell
    docker-compose up --build frontend
    ```
