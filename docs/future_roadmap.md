# 🚀 Future Roadmap & Todo List

현재 배포된 MVP(최소 기능 제품)를 발전시키고, 프로젝트 발표를 준비하기 위한 향후 계획입니다.

---

## 🎨 1. UI/UX 개선 (Simple & Concise)
복잡한 기능을 덜어내고, 사용자가 핵심 가치(에너지 거래)에 집중할 수 있도록 직관적인 UI로 개편합니다.

*   **메인 대시보드 간소화**: 복잡한 차트나 지표 대신, 현재 에너지 가격과 내 트럭 상태만 크게 표시.
*   **직관적인 거래 버튼**: '구매' / '판매' 버튼을 크게 배치하고, 모달 창으로 심플하게 거래 진행.
*   **불필요한 컴포넌트 제거**: 데모 시연에 방해되는 미구현 메뉴나 자잘한 정보 패널 삭제.

## 🔗 2. API 연동 (Integration)
현재 하드코딩된 모의 데이터(Mock Data)를 실제 백엔드 서버와 연결합니다.

*   **실시간 가격 연동**: 백엔드에서 생성하는 시뮬레이션 가격을 프론트엔드 차트에 반영.
*   **트럭 매칭 시스템**: 프론트엔드에서 거래 요청 시, 백엔드 로직을 통해 가장 가까운 트럭과 매칭.
*   **데이터 흐름 검증**: `Supabase DB` <-> `FastAPI Backend` <-> `Next.js Frontend` 흐름이 끊기지 않는지 확인.

## 🎤 3. 발표 및 데모 준비 (Presentation)
프로젝트의 가치를 효과적으로 전달하기 위한 자료를 준비합니다.

*   **발표 자료 (PPT/Keynote)**:
    *   **문제 정의**: 왜 P2P 에너지 거래가 필요한가?
    *   **해결 방안**: Energy Truck이 어떻게 해결하는가? (알고리즘, 아키텍처)
    *   **기술적 챌린지**: Terraform, AWS Fargate, CI/CD 등 사용 기술 강조.
*   **데모 시나리오**:
    1.  사용자가 앱에 접속하여 현재 가격 확인.
    2.  '에너지 판매' 요청 클릭.
    3.  지도에서 주변 트럭이 매칭되어 다가오는 모습 시연.
    4.  거래 완료 후 정산 내역 확인.

## 🤖 4. 향후 과제 (Future Works)
이번 프로젝트 기간 내에 완성하지 못하더라도, 앞으로 발전시킬 뱡향성입니다.

*   **Jenkins 완전 자동화**: 현재 반자동인 배포 과정을 Git Push 한 번으로 끝나는 'Zero-Touch' 파이프라인으로 구축.
*   **테스트 코드 작성**: PyTest(백엔드) 및 Jest(프론트엔드)를 통한 안정성 확보.
*   **보안 강화**: HTTPS 적용 (SSL 인증서) 및 WAF(방화벽) 도입.
